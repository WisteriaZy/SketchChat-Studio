工具只读取图片，不会替你把文件复制进项目。

2写字区域 · 可手动微调

请在图片上拖动，选择一个矩形。

左上角为 (0, 0)，向右为 X，向下为 Y。右下角填坐标，不是宽高。

3单底图配置片段

默认关闭原角色的手部遮挡图层，只保留普通表情和 Alt+1。此片段不是完整的 config.yaml。

换图前后，只需要这几步
  1. 将图片放进项目的 BaseImages 文件夹。推荐使用已摆正方向的 PNG。
  2. 框出矩形写字区域。不要把边框、手指等不能写字的位置框进去。
  3. 在 config.yaml 中替换同名配置项/整个映射段，不要重复追加，也不要覆盖整个文件。其它热键、延迟等设置保持不变。
  4. 在原启动窗口按 Ctrl+C 停止，再双击 Start.cmd，先在自己的聊天里测试。

不同表情共用一套坐标；保留多表情时请让白板位置一致，并自行保留对应映射和快捷键。这里不支持四点透视，也不模拟实际字体排版。JPEG 的方向信息可能与 Python 解码结果不同，建议先转成 PNG。
