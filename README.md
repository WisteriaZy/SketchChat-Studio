# 绘聊工坊 · SketchChat Studio

**把一句话，放进角色的画板里。**

绘聊工坊是一款面向 Windows 的本地图片聊天工具：管理不同角色和表情，为底图设置文字区域，在聊天输入框中通过快捷键生成图片，再按需粘贴或发送到 QQ、微信等应用。

从换一张底图，到整理一套角色表情，都可以在桌面界面里完成，不必手动计算坐标或反复修改 YAML。

> 当前定位：可日常使用的桌面第一版。聊天集成通过键盘与剪贴板自动操作实现，并非 QQ/微信官方接口；效果受输入法、窗口焦点、权限和应用响应速度影响。建议先关闭自动发送，在自己的聊天窗口测试。

## 功能

| 功能 | 说明 |
| --- | --- |
| 多角色与多表情 | 新建、重命名、复制角色，批量导入底图，管理表情标签与默认表情 |
| 可视化布局 | 拖拽框选、移动和缩放写字区域；支持原始像素坐标微调 |
| 布局继承 | 每个角色拥有默认布局，特殊表情可以独立设置 |
| 字体与遮挡层 | 调整字体、颜色、最大字号、对齐与行距，导入透明 PNG 遮挡层 |
| 效果预览 | 纯文字、纯图片、图文混排；导出不含编辑框的 PNG |
| 自定义标签 | 支持 `#开心#`、`/开心`、`:)` 等格式，仅匹配消息开头 |
| 快捷键录制 | 录制生成键、发送键和表情快捷键；支持增删映射与冲突检查 |
| 单次表情模式 | 可关闭表情跟随，让指定表情仅用于本条或下一条消息 |
| 托盘运行 | 图标显示监听状态，左键切换监听，右键打开管理器或退出 |
| 本地素材库 | 导入素材自动复制，支持备份；删除角色移入可恢复目录 |

编辑草稿与聊天当前使用状态分离：**浏览角色、调整预览不会悄悄切换聊天底图。**

项目仓库：[WisteriaZy/SketchChat-Studio](https://github.com/WisteriaZy/SketchChat-Studio)。

## 快速开始

### 已配置好的本地项目

双击项目根目录中的 **`StartStudio.exe`**。

- 不依赖 VBS，不显示终端；管理器正常显示。
- 启动时默认暂停监听，请先确认效果，再主动启用。
- 更新代码后，需要从托盘选择“退出”再重启。关闭窗口只是隐藏到托盘。
- **EXE 是轻量启动器，不是独立完整安装包。** 不能只复制这一个文件；需要项目源码、Python 环境和素材库。

### 从源码安装

要求：**Windows 10/11、Python 3.10+**。当前本机测试环境为 Python 3.13。其他系统暂不支持聊天监听。

首次获取源码：

```powershell
git clone https://github.com/WisteriaZy/SketchChat-Studio.git
cd SketchChat-Studio
```

在项目根目录打开 PowerShell：

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe desktop.py
```

最后一条是便于排错的终端启动方式。日常无终端启动使用 `StartStudio.exe`；若源码中未附带该文件，可在安装有 .NET Framework C# 编译器的 Windows 上构建：

```powershell
powershell -NoProfile -File .\launcher\Build.ps1
```

不要同时启用旧版 `Start.cmd` / `main.py` 与桌面版监听，否则快捷键可能冲突。旧 VBS 启动入口已弃用。

## 第一次使用

1. **创建或选择角色**：批量导入底图，每张图对应一个表情。
2. **设置默认布局**：右侧切到“角色默认布局”，在底图上框出写字区域，选择字体。
3. **调整特殊表情**：切到“当前表情布局”，取消“继承角色布局”，单独调整区域或遮挡层。
4. **预览并保存**：下方输入测试文字或选择测试图片，检查效果后保存角色。
5. **设为聊天当前角色／表情**：顶部会显示当前使用对象。
6. **设置快捷键**：打开“聊天设置”，点击“录制”，按下目标键并松开；推荐先尝试 `F8` 等不与输入法冲突的键。
7. **启用监听并试用**：确认允许进程、关闭自动发送，在聊天输入框里输入文字，按生成键检查粘贴效果。

预览不读取聊天输入框，不读取剪贴板，也不会发送消息。

### 布局继承的含义

```text
角色 A 的默认布局
├─ 普通：继承默认布局
├─ 开心：继承默认布局
└─ 举牌：独立布局
```

继承对象是**当前角色自己的默认布局**，不是默认表情，也不是上一个表情。修改默认布局会影响仍在继承的表情；独立布局不受影响。重新勾选继承会清除该表情的独立设置。

## 表情标签与快捷键

假设“开心”表情的聊天标签设为 `/开心`：

```text
/开心 今天真不错！
```

会使用该表情的底图，只将“今天真不错！”绘制到图片里。

- 标签必须在消息最开头，前面有空格也不触发；正文中间的标签保持原样。
- 按字面匹配，不使用正则。标签前缀重叠时优先最长的一个，每条只处理一个前缀标签。
- 不强制使用井号；同角色内标签必须唯一，不能含首尾空白或控制字符。
- 未知标签按普通正文处理，不跨角色查找。
- 表情快捷键在列表中绑定到聊天标签，只作用于聊天当前角色。修改标签后请同步修改快捷键目标。

### 跟随上一次表情

| 设置 | 行为 |
| --- | --- |
| 开启（默认） | 切换后持续使用该表情，直到下一次切换 |
| 关闭 | 普通消息使用角色默认表情；正文标签仅影响本条；表情快捷键或单独标签仅为下一条指定一次表情 |

单次模式在成功生成图片后恢复默认；生成失败不消耗待使用表情。重新配置或切换角色会清除待使用表情。

### 快捷键录制

点击“录制”后按键，松开全部按键完成；`Esc`、失去焦点或超时会取消，保留原值。也可以手动填写 `f8`、`right alt` 等键名。

打开设置会暂停聊天监听，保存或取消后均需手动重新启用。左右 Ctrl/Alt 的录制已兼容多种 Windows 扩展码，但底层监听库仍可能返回重叠扫描码，**不保证左右键能分别绑定不同功能**。系统保留组合键也可能被 Windows 抢先处理。

## 聊天与托盘

- 托盘 **绿色勾号 = 监听中**，**灰色暂停符号 = 已暂停**。
- 左键单击切换监听；右键菜单打开管理器、切换监听或退出。双击无独立操作。
- 生成图片保留在剪贴板，可选择自动粘贴、自动发送或手动粘贴。
- **默认不读取剪贴板图片**，避免误把旧截图加入消息。需要配图时，在设置中明确开启，使用后建议关闭。
- 聊天图文混排只支持一张剪贴板配图；不解析输入框中的多张图片。自动操作需能剪切出文字，例如正文或表情标签。
- 默认操作间隔至少 **0.25 秒**，剪切确认超时 **2 秒**，粘贴后等待 **0.8 秒**再请求发送。
- 窗口切换、暂停、剪切超时或剪贴板内容被替换时停止后续操作；不会盲目重复粘贴和发送。

较慢的聊天客户端可尝试将操作间隔设为 `0.4–0.5` 秒、粘贴等待设为 `1.2–1.5` 秒。延迟并不代表确认消息已成功发送。

## 素材、迁移与备份

首次启动若没有新素材库，会将旧 `config.yaml` 中的有效底图、字体与布局复制到新库，并备份旧配置。**不会覆盖原配置和素材。** 已存在素材库时不会重复迁移。

```text
library/
├─ library.yaml                 全局设置、当前角色、表情状态
├─ characters/<角色 ID>/
│  ├─ character.yaml             角色信息、默认布局、表情及覆盖项
│  └─ assets/                    底图、字体、遮挡层
├─ backups/                     迁移前配置备份
├─ trash/                       已删除角色
├─ studio.log                   桌面运行日志
└─ launcher.log                 启动错误与标准输出/错误
```

点击“备份素材库”保存已落盘的数据；未保存草稿不在备份中。也可退出程序后复制整个 `library/`。

用以下命令打开其他素材库：

```powershell
.\.venv\Scripts\python.exe desktop.py --library "D:\MyCharacters"
```

素材使用相对路径，名称变更不影响内部 ID。迁移到其他电脑时应重新创建 Python 虚拟环境，不要依赖直接复制 `.venv`。个人素材库、日志和测试截图默认被 Git 忽略；发布前仍应检查旧 `BaseImages/`、字体及配置中是否含个人内容。

## 常见问题

| 问题 | 处理方式 |
| --- | --- |
| Enter 与输入法冲突 | 录制一个未占用的生成键，发送键可以继续保留 Enter |
| 按键没反应 | 确认监听已启用、焦点在输入框、前台进程在允许列表内，且没有同时启动旧监听 |
| 已剪切但没粘贴 | 检查状态栏及 `library/studio.log`；不要连续按键，先关闭自动发送定位问题 |
| 误加剪贴板图片 | 关闭“使用剪贴板图片作为配图” |
| 字体乱码或缺字 | 导入含所需中文字符的 TTF/OTF/TTC 字体 |
| 区域或遮挡层报错 | 坐标按底图原始像素填写；遮挡层尺寸须与底图一致 |
| 看不到修改效果 | 保存角色；确认聊天当前选择；更新程序后从托盘彻底退出再重开 |
| 启动失败 | 查看 `library/launcher.log`；或使用 `python.exe desktop.py` 从终端排查 |

## 当前边界

- 暂不支持 macOS/Linux、倾斜透视排版、绘画抠图或多图消息解析。
- 暂无角色压缩包分享、自动更新、独立完整安装包。
- 固定浅色界面，不随 Windows 暗色控件配色混搭。
- 不提供聊天平台官方集成，也不能保证所有输入法、权限组合和客户端版本都兼容。
