# 绘聊工坊 · 使用手册

## 启动

双击项目目录下 **`StartStudio.exe`**，或运行：

```powershell
.\.venv\Scripts\python.exe desktop.py
```

桌面版要求 **Windows 10/11、Python 3.10+**。需在虚拟环境内安装 PySide6 等依赖。
重新部署时创建虚拟环境并安装 `requirements.txt`。暂未打包单文件 EXE。

**不要同时运行旧 `Start.cmd` / `main.py` 和新桌面版的聊天监听**，否则快捷键可能相互冲突。
旧启动方式保留；它仍读取原来的 `config.yaml`，不会读取新素材库。

默认启动入口 `StartStudio.exe` 是 .NET Framework Windows 图形启动器，通过 CreateNoWindow 启动项目内 Python，不依赖 VBS、不创建终端窗口。`StartStudio.cmd` 会转交 EXE，但 CMD 本身可能短暂闪窗，建议直接双击 EXE。旧 VBS 不再使用。管理器正常显示，监听仍默认暂停，日志在 `library/studio.log`。此 EXE 不是独立完整软件包，必须与项目代码和 `.venv` 一起保留；启动器按相对目录寻找 Python；虚拟环境跨机器或移动后可能需要重建。启动器源码在 `launcher/StudioLauncher.cs`，用 `launcher/Build.ps1` 重建。

## 现有配置怎样迁移

第一次启动读取原 `config.yaml` 实际生效的内容，建立“我的角色（旧配置）”。
底图和字体复制到独立素材目录；原配置备份到 `library/backups/`，**不覆盖或删除原文件**。
YAML 重复键仍按旧加载器“最后一项生效”的结果迁移。
空路径或不存在的遮挡层不启用；缺失底图跳过并给出提示。
已存在 `library/library.yaml` 时不会重新导入旧配置。

迁移后的角色可以在管理器中检查并调整，旧配置不会随新界面修改而同步更新。

## 编辑与使用

1. 左侧选角色，下方选表情。**浏览与编辑不改变聊天当前使用的角色**。
2. 右侧选择“角色默认布局”，修改该角色共用的区域、字体、颜色、字号、对齐、行距和遮挡层。
3. 如某个表情构图不同，选择“当前表情布局”，取消“继承角色布局”，然后独立调整。
   重新勾选继承将清除该表情的独立设置。独立布局复制当时的默认布局，不随以后的默认值变化。
4. 在画布空白处拖出矩形；拖框内移动、拖四角缩放。滚轮缩放画布，中键平移，“适应窗口”还原视图。
   数值始终是**底图原始像素坐标**，右下角不是宽高。
5. 下方测试文字、选择测试图片，查看纯文字、纯图片或图文混排。清空文字即可测试纯图片。
   预览不读剪贴板、不触发快捷键、不发送消息。导出 PNG 不包含编辑蓝框。
6. 点击“保存角色”。未保存修改只存在于编辑草稿，切换角色或退出时会询问保存/丢弃/取消。
7. 点击“设为聊天当前角色 / 表情”。顶部会显示实际使用对象。

每个角色至少保留一个表情。角色重命名不改变内部 ID 或素材路径。
新建角色导入底图后会保存一个可编辑的初始角色，请再确认默认写字区域。
批量导入表情默认采用文件名作为名称；重名自动加编号，名称与聊天标签均可编辑。标签可自定义为 `/开心`、`[开心]`、`:)` 等，不强制使用井号。
同角色内标签必须唯一。不同尺寸底图导入时可按比例换算区域，换算后需预览确认。
无效区域、缺失素材和遮挡层尺寸不匹配会提示，不能覆盖上一次有效保存。
删除角色会移动到 `library/trash/`；删除表情仅移除配置项，不立即删除素材文件。

## 聊天监听

- 每次启动默认**暂停**；确认效果后主动点击“启用聊天监听”。
- “聊天设置”可修改生成键、发送键、允许进程、延迟、自动粘贴/发送和表情热键。
- 首次使用建议关闭“自动发送”，先在自己的聊天窗口验证；设置保存后监听暂停，需重新启用。
- 标签必须位于消息最开头（前面有空格也不会触发），只查找当前角色。按字面精确匹配，不是正则表达式；多个标签前缀重叠时优先最长的一个。
- 只移除开头匹配到的一个标签及紧接着的空白，正文中再次出现的标签保持原样。正文中间或末尾的标签、未知标签不触发切换。旧 `#开心#` 标签仍可用。
- 标签不能为空、不能含首尾空白或控制字符；同角色标签必须唯一。建议使用明显分隔符避免普通文字开头意外匹配。修改标签后若使用表情快捷键，需要在聊天设置中同步更新其目标标签。
- 默认 `Alt+1` 等快捷键针对当前角色；该角色没有对应表情时不切换。
- 切换角色时记住上次使用的表情，首次使用默认表情；保存活动角色后下一次生成读取新配置。
- **默认不读取剪贴板里的图片**，避免把之前复制的截图、表情包误当作配图。需要图文混排时，在“聊天设置”明确勾选“使用剪贴板图片作为配图”；使用后建议关闭。
- 生成的图像保留在剪贴板。关闭自动粘贴时可手动粘贴；自己的上一次输出不会被再次套入底图。
- 自动操作前台 QQ/微信仍依赖应用快捷键、权限与响应速度，真实发送结果须在聊天窗口确认。
  开启配图后，剪贴板中的图片作为配图；不会从聊天输入框解析多张图片。
  聊天自动操作需要能从输入框剪切到文字（例如正文或表情标签）；空输入框不会盲目发送剪贴板图片。纯图片也可在编辑器预览并导出。
- 生成键在松开时触发；操作间隔默认且最低 0.25 秒，粘贴后默认等待 0.8 秒才请求发送，剪切确认超时默认 2 秒。旧库低于 0.25 秒的间隔运行时自动提升，无需手动修改文件。
- 全选和剪切分开等待，剪切后确认剪贴板已更新且可读取文字。剪贴板暂时占用会限时重试访问，但不会重发剪切、粘贴或发送按键。
- QQ/微信响应慢时，可将操作间隔提高至 0.4–0.5 秒、粘贴后等待提高至 1.2–1.5 秒；延迟并不代表已确认消息发送成功。
- 生成中若前台窗口切换，不向新窗口自动粘贴/发送；出错时尽量把已剪切文本保留在剪贴板供恢复。
- 关闭窗口隐藏到托盘；左键单击托盘切换监听，右键菜单可打开管理器、切换监听或退出；双击不再打开窗口。无托盘环境关闭即退出。

## 界面主题

桌面界面使用固定浅色 Fusion 风格与完整调色板，不跟随 Windows 暗色控件颜色，避免白底白字或黑白混搭。主窗口、设置弹窗、菜单和禁用态保持一致；系统原生文件选择器由 Windows 自行绘制。
更新代码后需要从托盘“退出”，再启动 `StartStudio.exe`，只关闭窗口隐藏到托盘不会加载新版代码。

## 数据结构与备份

```text
library/
  library.yaml                  # version: 1，全局聊天设置、当前角色、各角色上次表情
  characters/<角色稳定ID>/
    character.yaml              # version: 1，角色名称、默认表情、默认布局、表情列表
    assets/                     # 自动复制的底图、字体、遮挡层；配置使用相对路径
  backups/                      # 原配置备份
  trash/                        # 已删除角色
  studio.log                    # 桌面运行日志
```

表情含 `id/name/tag/image/overrides`；角色默认 `layout` 中有区域、字体、颜色、最大字号、对齐、行距、遮挡层和换行算法。
`overrides` 缺少的键继承角色布局；`overlay: null` 明确关闭遮挡层。
YAML 保存先写临时文件再原子替换，不使用数据库。

点击“备份素材库”将已保存的整个素材库复制到所选目录；未保存草稿不在备份中。
也可以退出后直接复制 `library/` 文件夹。用 `desktop.py --library 路径` 打开其他素材库。
同一素材库用锁文件防止重复开启管理器。恢复删除角色时，退出管理器，将 trash 内的角色目录搬回
`characters/` 并恢复为其 `character.yaml` 中的原始 ID 目录名，再启动。

首版不含角色压缩包分享、绘画/抠图、旋转/四角透视、多图聊天消息解析。

## 验证

```powershell
.\.venv\Scripts\python.exe -m unittest discover -s tests -v
# 显式核对真实配置迁移与离屏截图，不启用聊天监听：
.\.venv\Scripts\python.exe tests/verify_real_library.py
```

后者在 `.implementation-check/` 下输出界面截图和 PNG 效果图。
自动化测试使用模拟键盘/剪贴板，不向 QQ 或微信发送任何真实消息。

## 快捷键录制

在“聊天设置”中，生成键、发送键和每一条表情快捷键均可点击“录制”，然后按下目标单键或组合键，松开全部按键完成。
例如点击生成键旁的录制后按右 Alt，显示为 `right alt`。仍支持手动输入。
Esc 取消录制，失去焦点或 10 秒未完成也会取消并保留原值；Esc 本身可手动填写为 `esc`。
打开设置即暂停聊天监听，保存或取消后均需主动重新启用，避免录制时触发旧快捷键。

表情快捷键改为可增删的列表：左侧录制按键，右侧选择或输入聊天标签。自定义标签（如 `/开心`、`:)`）同样支持。
下拉建议来自已保存角色的标签；快捷键实际只查找聊天当前角色，未找到标签时不切换。
添加行必须填完整；不需要的行请删除。保存检查空键、无效键、多步骤按键和实际扫描码冲突，不仅比较输入字符串。
Windows 的 keyboard 后端可能为左右 Alt/Ctrl 返回重叠扫描码，因此不能保证它们能分别绑定不同功能，重叠时会拒绝保存。
系统保留键（例如 Alt+Tab、Win+L）可能被系统抢先处理，不能保证录制或监听；建议 F8、F9 或不冲突的组合键。


## 托盘状态与单次表情

托盘绿色勾号表示监听中，灰色暂停符号表示已暂停；悬停显示监听状态和当前角色/表情。
左键单击直接切换监听，右键菜单打开管理器，不再设置双击打开行为。

聊天设置新增“跟随上一次表情”，默认开启以兼容旧行为。关闭后：
- 不带标签的消息使用当前角色的默认表情。
- 正文开头的表情标签只影响本条，成功生成后恢复默认表情。
- 表情快捷键或单独输入的表情标签只为下一条准备一次表情；生成后恢复默认。
- 渲染失败时不会消耗待使用的表情；重新配置/切换角色会清除待使用表情。

左右 Ctrl/Alt 录制现在兼容更多 Qt/Windows 扩展扫描码，并在必要时查询左右键状态；
已识别的按下键会保留至释放，避免释放时被误判为左侧。真实键盘仍可能受驱动或 AltGr 布局影响，
且 keyboard 后端的左右键监听扫描码重叠限制仍存在；此修复不保证能把两侧分别绑定为不同功能。


启动器现改用 `python.exe` 配合 Windows `CreateNoWindow`，标准输入/输出/错误全部重定向，不依赖 pythonw 的控制台行为。启动器在管理器运行期间保持运行以收集输出，正常退出后一起结束。桌面运行日志只写 `library/studio.log`，早期启动错误和第三方输出写 `library/launcher.log`。`StartStudio.exe --verify-launch` 可运行无界面探针检查 Python 是否关联控制台，不启动聊天监听。


## 首次初始化向导

启动器现在先离线检测环境；缺失依赖时需点击“确认安装 / 修复”才会创建 `.venv` 并联网安装 requirements.txt。安装进度和异常保存在 `library/setup.log`。已就绪的环境不运行 pip。系统 Python 需用户自行安装；残缺环境不会自动删除。初始化失败可重试，取消确认则不启动应用。
